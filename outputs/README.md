# Generated outputs

Running `source("run_analysis.R")` creates four subdirectories here:

- `figures/`: publication figures in PNG and PDF formats;
- `tables/`: manuscript tables in DOCX and XLSX formats;
- `source_data/`: aggregated data underlying tables and trajectory figures;
- `model_results/`: fixed-effect estimates and model diagnostics.

The final reviewed outputs may be committed to the public repository. Do not add patient-level datasets, fitted model objects containing model frames, or temporary exports that could contain identifiers.
